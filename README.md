# Клиентские веб-приложения — лабораторные работы

Вариант 2 — товары (Products) из [DummyJSON](https://dummyjson.com/docs/products).

| Папка | Работа | Стек |
| --- | --- | --- |
| [lab1-products](lab1-products) | ЛР1: интерфейс для работы с товарами | React 19, TypeScript, Vite |
| [lab2-products](lab2-products) | ЛР2: приложение на Next.js App Router с данными из API DummyJSON | Next.js 16, React 19, TypeScript, Zustand |

Отчёты лежат в папках `Отчет` внутри каждой работы.

## Запуск

Каждая работа запускается из своей папки:

```bash
cd lab1-products   # или lab2-products
npm install
npm run dev
```
